# Aleana&Carlup
=============

## Descripción
-----------

Aleana&Carlup es un proyecto desarrollado para una empresa suéterera, diseñado para gestionar el inventario, pedidos y clientes de manera eficiente. Utiliza el modelo arquitectónico MVC para una estructura organizada y mantenible.

## Tecnologías Utilizadas
----------------------

*   PHP
*   AJAX
*   HTML
*   CSS
*   JSON
*   MySQL

## Plugins Utilizados
----------------------

*   Data Tables

## Estructura del Proyecto
-----------------------

El proyecto sigue una estructura MVC (Modelo-Vista-Controlador) para separar la lógica de negocio de la presentación. Las principales carpetas del proyecto son:

*   **Model**: Contiene las clases que interactúan con la base de datos y encapsulan la lógica de negocio.
*   **View**: Contiene los archivos HTML y CSS para la interfaz de usuario.
*   **Controller**: Contiene los controladores que manejan las solicitudes del usuario y coordinan la interacción entre el modelo y la vista.
*   **Config**: Contiene archivos de configuración, como la configuración de la base de datos.

## Configuración
-------------

1.  Clona el repositorio en tu máquina local.
2.  Importa la base de datos desde el archivo `database.sql`.
3.  Configura la conexión a la base de datos en el archivo `Config/Config.php`.
4.  Abre el proyecto en tu servidor local.

## Uso
---

1.  Accede a la aplicación desde tu navegador.
2.  Explora las diferentes funcionalidades, como la gestión de inventario, pedidos y clientes.
3.  Realiza pruebas de funcionalidad y asegúrate de que todo esté funcionando correctamente.
